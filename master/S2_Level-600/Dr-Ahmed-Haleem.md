# GBE601 — Zero Energy Building Design

## Lecture 2 — من المناخ والبرنامج الوظيفي لأهداف الأداء

### نواتج التعلم
تحليل الطقس **خلال ساعات الإشغال الفعلية** — استخلاص درس من كل حالة — ربط كل قرار بمصدر وعدم يقين — قيود الخدمة والمناخ والتنفيذ في مصر — بناء **load budget** واختبار تغيّر ساعات التشغيل.

### Part A — المناخ والبرنامج الوظيفي

**من الأدلة إلى المستهدفات (4 خطوات):**
1. **Scientific basis** — التكيّف المناخي وخدمات المبنى
2. **Project evidence** — الطقس، قيود الموقع، جداول المستخدمين
3. **Testable hypothesis** — تغيير محدد + آلية + اختبار قبول
4. **Performance brief** — موازنة طاقة + راحة + IAQ + طريقة تحقق

**توثيق ملف الطقس (Weather file provenance) ⭐:**
1. التعريف: محطة الـ **EPW**، الإحداثيات، الارتفاع، التوقيت، المصدر
2. الفترة: سنة نموذجية (Typical) ولا سنة فعلية؛ البيانات الناقصة
3. ملاءمة الموقع: الساحل والعمران والتضاريس ممكن يختلفوا عن المحطة
4. الأرشفة: الملف، الإصدار، تاريخ التحميل، خطوات المعالجة

**المناخ خلال ساعات الإشغال:** مدى الحرارة (شهري/يومي) — الرطوبة (توزيع سيكرومتري) — التعرض الشمسي (اتجاه وتوقيت) — الرياح (اتجاه، سرعة، عوائق) — **Heatmap للطقس مقابل جدول التشغيل** — Climate Consultant بيقترح فرضيات (SBSE).

**من البرنامج لجدول التشغيل:**
| الفراغ | البيانات المطلوبة | القرار المتأثر |
|---|---|---|
| فصول | جدول، أعداد، إجازات، نظافة | ساعات التهوية والإنارة |
| ورش/استوديوهات | استخدام مسائي، معدات، سحب | نطاق ممتد + أحمال عمليات منفصلة |
| IT/أمن | خوادم، تبريد، أجهزة أساسية | **حمل مستمر + عداد منفصل** |
| خدمات/حركة | دخول، تنظيف، تخزين | **متعاملش كل فراغ كأنه فصل** |

**الأحمال الحرجة:** الأشخاص (كسب داخلي + هواء خارجي) — العمليات (معامل، مطابخ، IT، مياه ساخنة) — العمارة (عمق، تجاور، إتاحة السطح) — السلامة (التهوية الأساسية) — التشغيل (افصل المستمر عن المتقطع) — **جدوى هدف الطاقة بتتبع موجز الخدمة (Service first)**.

**مجموعة مؤشرات الأداء ⭐:**
| المؤشر | التعريف | أساس القبول |
|---|---|---|
| **EUI** | الطاقة الموردة سنويًا ÷ المساحة المعلنة | نفس المساحة والوقود والفترة والخدمة |
| **Peak demand** | أقصى kW خلال فترة محددة | يوم التصميم، المعدات، التنوع |
| **Thermal comfort** | ساعات الإشغال بمنهج محدد | **ASHRAE 55** |
| **IAQ** | هواء خارجي + ضبط الملوثات | الاشتراطات المحلية + **ASHRAE 62.1** |
| **Solar opportunity** | مساحة متاحة، تظليل، توليد سنوي | هندسة وطقس وفواقد موثقة (**PVWatts**) |

### Part C — قرارات ما قبل التصميم
**دراسات قبل تثبيت التصميم:** (1) الموقع والمناخ → خريطة قيود (ظل، ضوضاء، غبار) — (2) المستخدم والخدمة → اعتماد الجداول والأحمال الحرجة — (3) الطاقة والسطح → موازنة الاستخدامات مع السطح المتاح للتوليد — (4) التنفيذ والتكلفة → تراكيب محلية، مهارات، صيانة، أسعار.
كل دراسة لازم تنتهي بـ **قرار + مسؤول + فجوة أدلة**.

**سجل الأدلة (Evidence Register) ⭐:**
| الحقل | المحتوى | فايدته |
|---|---|---|
| المتغير والوحدة | القيمة، الفراغ، الفترة، حدود الحساب | يمنع خلط قدرة الذروة (kW) بالطاقة السنوية (kWh) |
| المصدر ونوع الدليل | **مقاس / موثق / محسوب / مفترض / ناقص** | يفصل التقديرات عن الرصد |
| المسؤول والتاريخ | مين، تاريخ الإصدار، المراجعة | تتبع تغيير الافتراضات |
| عدم اليقين والإجراء | المدى، والرصد التالي المطلوب | يقدّم البيانات المؤثرة على القرار |

**موجز الأداء القابل للاختبار:** موازنة طاقة (كهرباء سنوية ومخصصات) — راحة حرارية (ساعات خارج المعيار) — تهوية/IAQ — شمس/شبكة (حدود PV، فواقد، نقاط القياس) — **المساءلة** (مسؤول + رد فعل لو الاختبار فشل).

**مقارنة اختبارات التصميم (5 خطوات) ⭐:** (1) حالة مرجعية ثابتة (وظيفة، مساحة، جداول، طقس) → (2) **فرضية واحدة** (غيّر متغير واحد) → (3) نتائج مترابطة (طاقة، ذروة، راحة، IAQ، تكلفة معًا) → (4) **Stress case** (مساء، مستخدمين أكتر، طقس أحر) → (5) سجل القرار (قبول/تعديل/رفض + الدليل اللي يعكسه).

### Part D — التطبيق في مصر
**الأقاليم واختبارات الخدمة** (مصدر الأقاليم: Guidehouse, Egypt EEBC analysis 2022 — HBRC):
| الإقليم | الوظيفة والأولوية | دليل القبول |
|---|---|---|
| الساحل الشمالي والشرقي | فندق: رطوبة، مياه ساخنة، أملاح | سجلات رطوبة وتهوية وصيانة |
| الدلتا والقاهرة | تعليم: حر، غبار، إشغال مسائي | EPW + جدول + تقييم الهواء الخارجي |
| شمال وجنوب الصعيد | مدارس: شمس وحر أثناء الدراسة | اختبار فرط الحرارة والتظليل |
| جنوب مصر/الصحراء | سكن: تبريد، مياه، تنظيف PV | موجات الحر، الاتساخ، خطة تنظيف |
| الهضاب/المرتفعات | إقامة: تدفئة موسمية، تكاثف | معايير الصيف والشتاء معًا |

**التنفيذ والتشغيل المستقبلي:** أدلة المواد المحلية (طوب، خرسانة، عزل: رطوبة وحريق) — الكود المصري الساري + **GPRS (الهرم الأخضر)** — أسعار محلية مؤرخة، استبدال، تنظيف، Commissioning — إتاحة السطح وسيناريو إجهاد حراري. أداة HBRC: **BUILD_ME BEP tool**.

### Part E — مثال محلول: مبنى تعليمي بالقاهرة ⭐⭐
**المدخلات (افتراضية للتدريس):** مساحة 1,200 م² — كله كهرباء
| البند | الافتراض | الحساب | kWh/yr |
|---|---|---|---|
| إنارة | 6 W/m² × 1,200 = 7.2 kW؛ 200 يوم × 8 س = 1,600 h | 7.2 × 1,600 | 11,520 |
| تجهيزات تعليمية | 4 W/m² = 4.8 kW × 1,600 h | 4.8 × 1,600 | 7,680 |
| حمل مستمر (IT/أمن) | 1 kW × 8,760 h | | 8,760 |
| HVAC + مراوح | مخصص مفترض | | 72,000 |
| مياه ساخنة | مخصص مفترض | | 4,000 |
| **الإجمالي** | | | **103,960** |

- **EUI** = 103,960 / 1,200 ≈ **86.63 kWh/m²·yr**
- **PV:** 450 م² × 0.16 kWp/m² = **72 kWp** × 1,500 kWh/kWp = **108,000 kWh/yr**
- احتياطي تخطيطي 10% = 10,800 → **هدف الطلب = 97,200 kWh/yr → EUI ≤ 81**
- **الخفض المطلوب = 103,960 − 97,200 = 6,760 kWh/yr**
- المعادلة: **E = Power × Equivalent full-load hours**

**اختبار تغيّر الاستخدام:**
- إنارة مسائية (80 يوم × 3 س × 7.2 kW) = **+1,728 kWh**
- HVAC +10% = **+7,200 kWh**
- الاتنين معًا: الطلب = **112,888** مقابل PV **108,000** → **عجز 4,888 kWh** ← المبنى يفقد الـ Zero

## Lecture 4 — الغلاف الحراري والراحة وجودة الهواء (Thermal Envelope, Comfort & IAQ)

### Part A — الغلاف والبيئة الداخلية
**مسارات الحرارة والرطوبة (4):**
1. **Conduction** — العزل بيبطّأ تدفق الحرارة
2. **Air flow** — إحكام التسريب + هواء خارجي مصمم
3. **Heat storage** — الكتلة بتغير **التوقيت**، العزل بيغير **المقاومة**
4. **Moisture** — التحكم في المطر والبخار ومسارات التجفيف معًا

**خواص التراكيب ⭐ (معادلات):**
| الخاصية | التعريف والوحدة | أثر القرار |
|---|---|---|
| Conductivity **λ** | W/(m·K) | استخدم ظروف اختبار المنتج |
| Layer resistance | **R = d / λ** (m²K/W) | السمك والموصلية |
| U-value | **U = 1 / R_total** (W/m²K) | ضمّن أغشية السطح والجسور الحرارية |
| الكثافة والسعة الحرارية | تخزين وتأخير زمني | نمذجة الدورة الحرارية الساعية |
| Thermal mass | **التخزين غير العزل** | افحص الشحن والتفريغ |

**الجسور الحرارية (4 خطوات):** تتبع استمرار العزل (حواف البلاطات، الحلوق) → نمذجة الوصلة بـ **THERM** → فحص حرارة السطح ونقطة الندى → **فحص الاستمرارية واختبار التسريب قبل التغطية**.

**اختيار منظومة الشباك (Whole-window) — LBNL WINDOW/THERM:**
- **U-factor** للشباك كله (زجاج + حافة + إطار)
- **SHGC** — قبول الشمس حسب التعرض الفعلي
- **VT** (نفاذ الضوء المرئي) — جنب التحكم الشمسي
- **Air leakage** — الجوانات ووصلات التركيب

**الإحكام والهواء المطلوب ⭐:**
| مسار الهواء | الدور/الخطر | الدليل |
|---|---|---|
| تسريب غير متحكم | حرارة وغبار ورطوبة غير محسوبة | إحكام الوصلات + القياس |
| هواء خارجي مصمم | تهوية حسب الاستخدام | توثيق التدفق والجدول والفلترة |
| سحب موضعي | إزالة الملوث من مصدره | هواء تعويض وضغط |
| **Blower-door n50** | تغيرات هواء عند **50 Pa** (h⁻¹) | **مش معدل تهوية للإشغال** |
| حفظ الخدمة | الهواء المطلوب ثابت في الحالتين | ASHRAE 62.1 / 62.2 / 170 |

**الراحة الحرارية (ASHRAE 55-2023) — 6 عوامل:** حرارة الهواء — الإشعاع (أسطح الشبابيك والحوائط) — سرعة الهواء (تفيد أو تعمل تيار) — الرطوبة — الملابس — النشاط (معدل الأيض).

**بوابات القبول:** رطوبة (تكاثف وتجفيف) → راحة (منهج صالح + عدم الراحة الموضعي) → تشغيل (تنسيق الإمداد والسحب والشبابيك) → **قبول: ارفض أي توفير طاقة لو الخدمة للمستخدمين فشلت**.

### Part C — ما قبل التصميم وبروتوكول الاختبار
**دراسات تقود القرار:** طقس ساعي وتعرض → موضع الطبقات وخواصها — المستخدمين والملوثات → الإمداد والسحب والفلاتر — المبنى القائم والمياه → جهة التجديد ومسار التجفيف (خريطة عيوب) — **المواد والمهارات المحلية → وصلات قابلة للتنفيذ + حماية حريق (Mock-up، شهادات اختبار، عرض سعر مؤرخ)** — طاقة وراحة وتكلفة → مقارنة حزم **بخدمة متكافئة**.
**اختبارات النموذج:** مرجع ثابت (كتلة الأسبوع 3) → توثيق الخواص (λ، كثافة، سعة، U/SHGC/VT) → **3 اختبارات حساسية منفصلة** (عزل، تسريب، زجاج) → قبول (طلب سنوي + ذروة + راحة + رطوبة معًا).

### Part D — تصميم الغلاف لمصر ⭐
| الإقليم | الحزمة المقترحة للفحص | الخطر |
|---|---|---|
| الساحل الشمالي/الشرقي | مناطق مكيفة محكمة + خطة رطوبة | دخول الرطوبة، الأملاح، المطر |
| **الدلتا والقاهرة** | **عزل السقف + إحكام وصلات الشبابيك** | **دخول الغبار وصيانة الفلاتر** |
| شمال/جنوب الصعيد | سقف معزول + كسب شمسي منخفض | سخونة الأسطح وقت الإشغال |
| الصحراء/الجنوب | عزل مستمر + جوانات معمرة | موجات حر، تقادم الجوانات، ليالي دافية |
| المرتفعات | توازن موسمي + الجسور | وصلات باردة وتكاثف |

**الغلاف حسب الوظيفة:** تعليم/مكاتب (عدم راحة إشعاعية قرب الزجاج؛ تهوية وصوت) — **سكن/فنادق (غرف هادية محكمة بهواء نقي؛ سحب الحمامات والمطابخ واحتياجات النوم)** — مستشفيات/معامل (ضغط ونظافة) — متاحف (استقرار) — صناعة (سقف، أبواب تحميل، سحب).
**التنفيذ في مصر:** توصيف (بيانات اختبار الطوب والخرسانة والعزل المحلي) → **تفصيل (تنسيق عزل مائي السطح، الحلوق، الحريق، طبقات الإحكام)** → مفاضلة (أسعار مؤرخة، صيانة، استبدال) → تحقق (اختبار الوصلات والتدفقات، موجة حر، تغيّر الاستخدام). مرجع: EGBC GPRS، ASHRAE 90.1.

### Part E — مثال محلول: حزمة العزل ⭐⭐
**الحائط** (A = 120 م²، ΔT = 12 K، R_base = 0.50 m²K/W):
| | مرجعي | معزول (d = 0.06 m, λ = 0.04) |
|---|---|---|
| R_total | 0.50 | 0.50 + 0.06/0.04 = **2.00** |
| U = 1/R | **2.00** W/m²K | **0.50** W/m²K |
| **q = U·A·ΔT** | 2.00×120×12 = **2.88 kW** | 0.50×120×12 = **0.72 kW** |

**التسريب والهواء المطلوب** (ρcp = 1,200 J/m³K، **q_air = ρcp × V̇ × ΔT**):
| | مرجعي | محسّن |
|---|---|---|
| تسريب V̇ | 0.10 m³/s → **1.44 kW** | 0.03 m³/s → **0.432 kW** |
| هواء خارجي مصمم (ثابت للخدمة) | 0.15 → **2.16 kW** | 0.15 → **2.16 kW** |
| **المجموع الجزئي** | **6.48 kW** | **3.312 kW** |

**الحساسية (تغيير متغير واحد من الحالة المحسّنة):**
- عزل أقل d = 0.03 → R = 1.25 → U = 0.80 → حائط = **1.152 kW**
- التسريب رجع 0.10 → **1.44 kW** (مع ثبات الهواء المصمم)
- حر أشد ΔT = 16 K → مجموع جزئي = **4.416 kW**
- **حدود:** ده حساب ثابت أحادي البعد (حمل محسوس بس)، مفيش جسور ولا شمس ولا حمل كامن — **مش إثبات طاقة سنوية أو راحة**

> لاحظ: الهواء الخارجي المصمم **ما اتقللش** في الحالة المحسّنة — ده المقصود بـ "retain ventilation / preserve service".

### مهمة الأسبوع 4

**التقييم:** Evidence 25% — Comparison 25% — Health 25% — Delivery 15% — Defence 10%.
**سؤال الخروج ⭐:** **ليه ممكن U أقل ويفشل المشروع؟** (لأن التسريب أو الهواء الخارجي أو التكاثف أو الراحة الإشعاعية أو الجسور الحرارية ممكن تفشّل الخدمة رغم تحسن U).

**عقد المخرجات والتحقق:** المتغير والوحدة (كهرباء vs حمل حراري) — الزمن والمكان — اختبار البرنامج: **ASHRAE Standard 140-2023** — مقارنة بالمقاس: **NMBE و CV(RMSE)** طبقًا لـ **ASHRAE Guideline 14-2023** — أدلة مستقلة (حساسات، mock-ups، نفق رياح) واحتفظ ببيانات خارج المعايرة.

### Part D — مصر (8 أقاليم — Mahmoud 2011)
| الإقليم | سؤال النموذج الأولوي | فحص محلي |
|---|---|---|
| الساحل الشمالي | طاقة: حمل كامن وتسريب | طقس بحري وتآكل |
| **الدلتا والقاهرة الكبرى** | **GIS + طاقة/إضاءة** | **ظل عمراني وجداول محلية** |
| شمال الصعيد | طاقة: سقف، كتلة، تبريد | هواء الليل والغبار |
| جنوب الصعيد/الجنوب | ذروة التبريد، المرونة الحرارية | طقس متطرف، ميزانية مياه |
| الساحل الشرقي/المرتفعات | رطوبة / تدفئة | الارتفاع والتعرض |
| الصحراء | ENVI-met/CFD + طاقة | مياه التربة، غبار، المدى الليلي |

**مسار Net-zero حسب الوظيفة:** مدرسة/القاهرة (EnergyPlus + Radiance بساعات حقيقية: غلاف → مراوح → تحكم → PV) — **سكن/الصعيد (طاقة + تهوية ليلية: سقف → كفاءة تبريد → PV)** — فندق/البحر الأحمر (حمل كامن + مياه ساخنة شمسية) — عيادة/ساحل (طاقة + CFD) — ورشة/صحراء (أحمال العمليات + اتساخ PV) — فراغ عام (Microclimate + موجات حر مستقبلية).

### Part E — مثال: ملحق عيادة (بيانات تركيبية)
- المساحة المساحية 1,000 م² vs المستوردة 900 م² → **فرق −10%** → **صلّح الاستيراد قبل المقارنة**
- عينة كهرباء: (2 + 3 + 4) kW × 0.5 h = **4.5 kWh** — بس ساعة ونص بيانات → **مفيش تقدير سنوي من عينة**
- الطاقة: OpenStudio/EnergyPlus + HVAC؛ الإضاءة: Honeybee/Radiance (حساس، سماء، شبكة)
- **مرفوض:** ENVI-met لحساب kWh سنوي (ظاهرة وحدود غلط)؛ ومفيش توفير طاقة من lx بس

**خطة فحص البيانات المقاسة:** طاقة (العداد، الطقس الفعلي، التوقيت) — ضوء (نفس الشبكة والسماء) — خارجي (هواء مظلل، رياح، إشعاع) — مقاييس الخطأ (NMBE، CV(RMSE)؛ bias، RMSE) — **Holdout** (بيانات مستقلة).

## 🏗️ الربط بمشروع ريفيل (العبور — إقليم القاهرة الكبرى)
- **الغلاف (L4):** حسب جدول د. حليم، أولوية القاهرة = **عزل السقف + إحكام وصلات الشبابيك + خطر الغبار**. في التشطيبات: مراجعة عزل الروف، جوانات وتركيب حلوق الألومنيوم (Air leakage)، واستمرار العزل عند حواف البلاطات والأعتاب (الجسور الحرارية) — مع **فحص قبل التغطية** (المحارة والجبس بورد).
- **حساب U للحوائط:** نطبق R = d/λ و U = 1/R_total على حائط الطوب الفعلي في ريفيل (مع/بدون عزل) ونربطه بحساب الكربون المجسد في مادة د. أشرف (مقايضة العزل).
- **السكن:** أولوية "غرف هادية محكمة بهواء نقي + سحب الحمامات والمطابخ" → مراجعة شفاطات الحمامات والمطابخ في التشطيب.
- **موازنة الطاقة (L2):** نعمل load budget لشقة/عمارة نموذجية في ريفيل (إنارة، أجهزة، تكييف، مياه ساخنة) + إمكانات PV على السطح → EUI ونسبة التغطية الشمسية.
- **المحاكاة (GAU503):** EPW القاهرة + نموذج DesignBuilder/Honeybee لوحدة نموذجية، مع **مراجعة نقل Revit → gbXML**.
